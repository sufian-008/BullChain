# 🚀 BullChain  

**BullChain** is a modern **full-stack web application** consisting of a **frontend**, **backend**, and an **admin dashboard**.  
It leverages cutting-edge technologies to provide **secure authentication**, **real-time interactions**, and a **seamless user/admin experience**.  

---

## ⚙️ Tech Stack  

### 🔹 Frontend (User App)  
- React 19  
- React Router DOM 7  
- Axios  
- React Toastify  
- React Cookie  

### 🔹 Backend (API)  
- Node.js + Express 5  
- MongoDB + Mongoose  
- JWT Authentication  
- Passport + Passport-local-mongoose  
- BcryptJS (secure password hashing)  
- CORS & Cookie-Parser  
- Dotenv for configuration  

### 🔹 Dashboard (Admin Panel)  
- React 18 + React Router DOM 6  
- Material UI (MUI)  
- Chart.js + react-chartjs-2 (data visualization)  
- Axios  
- React Toastify  

---

## 🚀 Features  

### ✅ Frontend  
- Clean, user-friendly interface  
- Secure login & registration  
- Cookie-based session handling  
- Toast notifications  

### ✅ Backend  
- RESTful API with JWT authentication  
- Encrypted password storage (bcrypt)  
- MongoDB integration  
- Environment-based configuration  

### ✅ Dashboard  
- Admin authentication system  
- Manage users & system data  
- Data analytics with interactive charts  
- Responsive Material UI design
